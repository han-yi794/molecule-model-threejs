操作指南 · 三维拖动辅助

🖱 鼠标操作

左键拖空白处旋转视角
滚轮缩放
右键拖平移视角
左键点原子选中，出现三轴手柄
左键拖原子按当前拖动方式移动
左键点键修改键序（单 / 芳香 / 双 / 三）
Ctrl / ⌘ + 点原子设置杂化（自动 / sp³ / sp² / sp）

⌨ 快捷键

x / y / z选中原子沿轴微移 0.1Å（Shift 反向）
Tab / Shift+Tab循环切换拖动方式
G网格吸附开 / 关（可对齐 0.25Å 网格）
0 / 1 / 2 / 3杂化：自动 / sp³ / sp² / sp
O / Shift+O优化单个原子 / 全局同步优化
Delete删除选中原子

✋ 拖动方式

平面自由拖任意方向自由移动，无辅助
三轴手柄拖彩色轴=沿轴移动；拖中心白球=平面移动
起始轴锁拖动时自动锁定最近的 x / y / z 世界轴
手柄 + 锁轴手柄与轴锁组合，点原子本体拖动也会锁轴

💡 提示

选中原子后出现三轴手柄；拖彩色轴时屏幕上方显示实时位移；接近可成键的原子时会发光提醒。单击原子=选中，按住拖动=移动。
